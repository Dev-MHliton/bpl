## 📖 Overview

React First Project BPL is a modern frontend starter template built using the latest React ecosystem tools. It focuses on fast development, clean architecture, reusable components, and scalable project structure using Vite, React, and Tailwind CSS.

---

## ✨ Features

- ⚡ Fast development with Vite
- ⚛️ React 19 component-based architecture
- 🎨 Tailwind CSS utility-first styling
- 📦 Clean and scalable folder structure
- 🔥 Hot Module Replacement (HMR)
- 🧹 ESLint configured for clean code

---

## 🛠️ Tech Stack

- React 19
- React DOM 19
- Vite 6
- Tailwind CSS 4
- React Icons
- ESLint
- Git & GitHub
